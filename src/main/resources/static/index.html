Reglas de Seguridad y Control de Acceso (RBAC)
  • ROLE_ADMIN: Acceso completo a las 16 sucursales, aprobación/rechazo de solicitudes, CRUD de empleados y eliminación de productos.
  • ROLE_GERENTE: Vista de inventario local y de las otras 15 sucursales, creación de solicitudes (requieren aprobación de Admin), y gestión de catálogo centralizado.
  • Sin Token (401): Cualquier petición no autenticada es rechazada con código HTTP 401.
  • Rol Insuficiente (403): Un gerente intentando acceder a endpoints de empleados o aprobando solicitudes recibe código HTTP 403.
  • Firma JWT: Algoritmo HMAC-SHA256 con llave secreta inyectada exclusivamente desde la variable de entorno JWT_SECRET.
Auditoría & Calidad de Código
  • JUnit 5 + JaCoCo: Cobertura mínima automatizada de pruebas del 80% sobre clases de servicio y controladores.
  • SonarQube: Análisis estático continuo de Bugs, Vulnerabilidades, Hotspots, Code Smells y Deuda Técnica.
  • OWASP ZAP: DAST activo y pasivo con cabeceras de seguridad HTTP configuradas en SecurityConfig (CSP, X-Frame-Options DENY, X-Content-Type-Options nosniff).
  • Pipeline CI/CD: GitHub Actions con etapas automatizadas de Test, Build y Deploy.
